# 钻孔三维缺陷分类后续实验计划

## 1. 当前任务特点

当前任务为 3D 钻孔缺陷二分类，缺陷主要集中在钻孔头部区域。

根据现有观察，缺陷的主要形态特征为：

- 正常样本：头部整体较平整；
- 缺陷样本：头部沿长度方向（D 方向）存在额外突出；
- 突出部分可能较短，也可能较长；
- 部分缺陷较细、较模糊，在下采样或全局平均过程中可能被削弱；
- 因此后续模型改进重点应放在 **保护 D 方向分辨率** 和 **增强 D 方向形态建模能力** 上。

---

## 2. 当前统一基线

后续实验统一以：

**Head40-533 3D ResNet18**

作为主要基线候选。

当前关键结构：

```text
输入：Head40
方向：统一到头部位于 D 轴高索引侧

Stem:
Conv3d kernel = (5,3,3)
stride = (1,1,1)

MaxPool:
kernel = (3,3,3)
stride = (1,1,1)

Layer1:
stride = 1

Layer2:
首块 stride = (2,2,2)

Layer3:
首块 stride = (2,2,2)

Layer4:
首块 stride = (2,2,2)

AdaptiveAvgPool3d(1)
Dropout
FC
```

继续保持：

- 相同的 22 板训练/验证池；
- 相同的五折划分；
- 相同随机种子；
- 相同数据增强；
- 相同归一化；
- 相同优化器和学习率策略；
- 相同 `best_loss` checkpoint 选择方式；
- 外部 3 板锁定测试集不参与模型选择。

## 3. 已完成实验

### 3.1 FullVolume 与 Head40

已验证头部区域裁剪有效。

```text
FullVolume-733
        ↓
Head40-733
```

Head40 在验证集和外部测试集上整体优于 FullVolume。

---

### 3.2 Stem D 方向卷积核长度

已完成：

```text
Head40-333
Head40-533
Head40-733
```

结果表明：

- `533` 的验证 OOF loss 最低；
- `533` 的验证 Recall、F1、AP 表现较好；
- `733` 部分 Accuracy、Precision、Specificity 略高；
- 外部测试上 `533` 与 `733` 差距很小。

因此后续优先以：

```text
Head40-533
```

作为结构改进基线。

---

### 3.3 ACB 非对称卷积

已完成：

```text
Head40-733
        ↓
layer1[0].conv1
333 + 133 + 313 + 331
```

结果未取得明确提升：

- 验证 OOF loss 上升；
- Accuracy、F1 等主要指标未改善；
- 外部测试仅 AUC 有极小变化；
- 结构复杂度增加，但收益不足。

### 当前决定

**传统四分支 ACB 路线停止继续扩展。**

暂不再做：

```text
533 + Full ACB
整个 Layer1 ACB
Layer2 ACB
多层 ACB
其他平面 ACB 排列组合
```

ACB 可作为论文中的补充负结果消融。

# 4. 后续实验总体思路

后续实验围绕一个核心问题展开：

> 如何尽量保留并增强钻孔头部沿 D 方向的细长突出特征？

优先级：

```text
1. 保护 D 方向分辨率
        ↓
2. 增强 D 方向局部形态
        ↓
3. 改进最终池化，避免突出特征被平均
        ↓
4. 构建专门的 D 方向特征分支
```

所有实验一次只改变一个因素。

---

# 5. 实验一：延迟 D 方向下采样

## 5.1 目的

当前 Head40 的 D 方向大致经过：

```text
40
↓ layer2
20
↓ layer3
10
↓ layer4
5
```

对于较细、较短的突出部分，D 方向压缩到 5 后可能导致局部形态被削弱。

因此首先测试：

```text
Layer2 stride:
(2,2,2)
    ↓
(1,2,2)
```

即：

- D 方向不在 Layer2 下采样；
- H/W 方向仍正常下采样。

新的 D 方向变化约为：

```text
40
↓ layer2
40
↓ layer3
20
↓ layer4
10
```

---

## 5.2 实验模型

### Baseline

```text
Head40-533
Layer2 stride = (2,2,2)
```

### Experiment D-Stride

```text
Head40-533-DKeep
Layer2 stride = (1,2,2)
```

其余完全不变。

---

## 5.3 观察指标

重点观察：

1. OOF loss
2. Recall
3. F1
4. AP
5. AUC
6. 外部测试泛化

尤其关注 Recall 和 F1，因为较模糊的小尖可能主要表现为漏检问题。

---

## 5.4 判断标准

如果：

- OOF loss 降低；
- Recall/F1 有稳定提升；
- 外部测试没有明显下降；

则保留该设计。

如果只提升单个很小指标、其余基本下降，则不继续扩大 D 保留范围。

---

# 6. 实验二：D 方向针对性非对称卷积

## 6.1 目的

传统 ACB 对三个空间平面同时增强，但当前缺陷先验明确：

> 最主要的判别信息来自 D 方向上的额外突出。

因此不再做完整 ACB，而只测试 **沿 D 方向的非对称卷积**。

---

## 6.2 第一版建议

在 `layer1[0].conv1` 位置使用：

```text
                ┌── 3×3×3 ──┐
输入 ───────────┤            ├── 相加
                └── 5×1×1 ──┘
```

含义：

- `3×3×3`：保留原始三维局部特征；
- `5×1×1`：专门增强 D 方向形态变化。

命名建议：

```text
Head40-533-DACB511
```

---

## 6.3 是否测试 3×1×1

如果 `333 + 511` 有提升，再补：

```text
333 + 311
```

比较：

```text
333
333 + 311
333 + 511
```

用于判断较短还是较长的 D 向局部感受野更适合。

如果 `333 + 511` 无提升，则不再继续这一系列。

---

# 7. 实验三：改进最终池化

## 7.1 问题

当前模型最终使用：

```text
AdaptiveAvgPool3d(1)
```

这会同时对：

```text
D、H、W
```

全部平均。

对于“整体大部分正常，只有局部存在细长尖部”的样本，异常响应可能被大量正常区域稀释。

---

## 7.2 推荐方案 A：H/W Average + D Max

先对 H/W 做平均：

```text
C × D × H × W
        ↓
C × D
```

保留完整 D 序列。

然后沿 D 做最大池化：

```text
C × D
   ↓
C
```

目的：

- H/W 平均描述整体横截面；
- D Max 保留最明显的突出响应。

命名建议：

```text
Head40-533-DMaxPool
```

---

## 7.3 推荐方案 B：Average + Max 融合

如果方案 A 有效果，可进一步尝试：

```text
D AvgPool
+
D MaxPool
```

然后拼接：

```text
512 + 512
    ↓
FC
```

但这一项只作为第二阶段，不与实验一同时修改。

---

# 8. 实验四：D 方向多尺度特征分支

## 8.1 目的

缺陷突出长度不固定：

```text
小尖
中等尖
较长尖
```

因此可以显式建立 D 方向多尺度特征提取。

---

## 8.2 推荐结构

从浅层或中浅层 3D 特征中提取 D 序列：

```text
3D Feature
C × D × H × W
        ↓
H/W Pooling
        ↓
C × D
```

然后建立：

```text
             ┌─ Conv1D k=3 ─┐
C × D ───────┼─ Conv1D k=5 ─┼── 融合
             └─ Conv1D k=7 ─┘
```

其中：

- `k=3`：偏向较短突出；
- `k=5`：中等尺度；
- `k=7`：较长突出。

最后与 ResNet 主分支融合：

```text
ResNet Layer4 → Global Pool ─────┐
                                 ├→ FC
D-direction branch ──────────────┘
```

---

## 8.3 H/W Pooling 建议

不要只使用 H/W Average。

建议：

```text
H/W Average Pool
+
H/W Max Pool
```

原因：

- Average 保留整体形态；
- Max 对局部细长突出更敏感。

---

## 8.4 是否立即做

不建议马上做。

先完成：

```text
实验一：D 下采样
实验二：D 向非对称卷积
实验三：池化
```

如果这些简单改动已经有效，再进入 D 多尺度分支。

---

# 9. 推荐实验执行顺序

严格按照以下顺序：

```text
Head40-533 Baseline
        ↓
① Layer2 D方向不下采样
   (2,2,2) → (1,2,2)
        ↓
② 333 + 511 D方向非对称卷积
        ↓
③ H/W Avg → D Max Pool
        ↓
④ D方向多尺度分支
   Conv1D 3/5/7
```

每次只修改一个因素。

# 10. 暂时不推荐继续的方向

当前不优先继续：

```text
传统 Full ACB
复杂空间注意力
大量 Layer 同时加模块
继续扩大 Stem D kernel 到 9/11
所有层取消 D 下采样
多个模块一次组合
大量 3/5/7/9 排列组合
重新调整数据增强
频繁调整 dropout
```

原因是这些实验要么已经没有明显收益，要么会引入过多变量，不利于判断真正有效因素。

# 11. 实验停止规则

为了避免无限试模型，建议设置明确停止条件。

## D 方向下采样

只做：

```text
Baseline
vs
Layer2 DKeep
```

若无提升，不继续 Layer3/Layer4 全部保留 D。

---

## D 方向非对称卷积

先做：

```text
333 + 511
```

只有有效时才补：

```text
333 + 311
```

若 `511` 无提升，停止该路线。

---

## Pooling

先做：

```text
H/W Avg + D Max
```

有效后再考虑 Avg + Max 融合。

---

## D 多尺度分支

只有前面实验表明“保留/增强 D 信息”确实有效时再做。

---

# 12. 最终论文实验链建议

如果后续实验有效，论文可以形成：

```text
原始 3D ResNet18
        ↓
头部 ROI
        ↓
Head40
        ↓
Stem D方向感受野消融
333 / 533 / 733
        ↓
Head40-533
        ↓
保护 D方向分辨率
        ↓
增强 D方向突出形态
        ↓
最终模型
```

核心逻辑：

> 钻孔缺陷主要表现为头部沿长度方向的局部突出，因此首先通过头部区域裁剪减少无关体积信息，再根据头部体积特点调整浅层 D 方向感受野，并进一步从 D 方向分辨率保持和形态特征增强两个方面提高模型对细长、模糊突出缺陷的识别能力。
