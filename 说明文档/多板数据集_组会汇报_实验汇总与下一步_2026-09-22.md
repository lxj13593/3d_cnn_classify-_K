# 多板钻孔三维缺陷分类：数据集、实验结果与下一步

> 组会汇报稿；结果核对日期：2026-09-22。下表均采用 **best_loss 检查点的五折算术均值**，百分数保留两位小数。五折验证与独立三板测试分开报告；不是五折预测拼接后的指标，也不是五模型集成结果。

## 1. 一句话结论

在当前 22 板训练/验证、3 板独立测试协议下，**原版完整体积 3D ResNet18 是整体实验基线**。Head40-733 是在它之后提出的 Head40 方法：五折 F1 为 88.86% 对基线的 87.64%，三板 F1 为 88.58% 对基线的 86.50%。Head40-533 是后续首层卷积消融及若干改动实验的局部对照，不是整体基线。继续叠加分支、池化或动态降权尚未获得稳定的额外收益；当前还需重点解决**模糊缺陷漏检**和**跨板差异**。

## 2. 数据集介绍

任务为单个钻孔三维 RAW 体积的**正常/缺陷二分类**：正常为 0，缺陷为 1。“清晰/模糊”是样本难度或标注来源分组，**不是第三类**。每个样本有对应二维图及来源记录。主实验将完整体积与基于 TOML `center2`、`bHeadUp` 定位的 **Head40** 钻头邻域比较；Head40 深度为 40，横截面包括 29×29、37×37、49×49。输入前统一深度方向，按单样本 P1/P99 归一化；训练采用相同五折划分。

| 用途 | 板数 | 正常 | 缺陷 | 总数 | 说明 |
|---|---:|---:|---:|---:|---|
| 训练/验证池 | 22 | 3,181 | 1,183 | 4,364 | 原 14 板加新增 8 板；固定五折，每个样本恰好验证一次 |
| 独立测试 | 3 | 556 | 222 | 778 | 板号 0024、0030、0031，均不进入训练或五折 |

训练池正常:缺陷约 **2.69:1**。下表只按“清晰/模糊”展示**有相应归属的样本**；模糊不等于错标。

| 训练池分组 | 正常 | 缺陷 | 合计 |
|---|---:|---:|---:|
| 清晰 | 2,257 | 588 | 2,845 |
| 模糊 | 924 | 144 | 1,068 |

清晰正常的 2,257 个包含原清晰标记的 2,170 个，以及从原始板补入、被数据说明计入“明显正常”的 87 个真实样本。**另有 451 个训练缺陷尚未标清晰或模糊**，所以不能硬归入上表；它们仍包含在 4,364 个训练/验证样本和全部总体指标中。

三块测试板分别有 **130、116、532** 个样本；0031 板占测试集 **68.4%**，所以三板合并指标受其影响较大。测试集正常样本中有清晰 **418**、模糊 **138**；缺陷 **222** 个有“缺陷”标签，但**未继续细分清晰或模糊**。这不是证明测试集中客观上没有模糊缺陷。因此，模糊缺陷能否检出，当前只能先看训练池的折外预测（OOF），不能用这三板测试分数作直接证明。

五折验证是**按孔划分，同一块板可能同时出现在训练折和验证折**；它衡量同板分布下的泛化，不能替代新板测试。三板与训练池板号隔离，但目前已被用于多次模型比较，后续不应再把它当作完全未触碰的模型选择集。

## 3. 所有已完成的多板实验

下列 17 组均在同一 22 板五折协议下报告。**原版完整体积 3D ResNet18 是整体基线**，其首层卷积核为 7×3×3。最初的 Head40 模型沿用该卷积核，即 Head40-733，作为与原版基线比较的 Head40 主方法。Head40-333 和 Head40-533 则是改变首层卷积核的消融版本；后续 E1～E4、池化、模糊权重等实验以 533 为各自的**局部对照**。除“完整体积”外，各方法都使用同一 TOML 定位的 Head40 裁剪、深度方向统一和 3D ResNet18 主干。`333/533/733` 表示 **首层卷积核的 D×H×W 尺寸**，分别为 3×3×3、5×3×3、7×3×3；不是网络层数或样本权重。未特别说明时，Layer4 后采用全局平均池化、Dropout(0.5) 和二分类全连接层。

具体改动如下；实验间只变动所列部分，其他数据划分、训练和测试协议保持一致：

| 方法类别 | 具体做法 |
|---|---|
| 输入与首层卷积 | 原版完整体积 ResNet18 不裁剪，首层卷积核为 7×3×3，首层卷积及随后的池化步幅均为 `(2,1,1)`；Head40-733 裁剪深度 40、保持 7×3×3 卷积核，为避免过早压缩深度，把这两处步幅改为 `(1,1,1)`。Head40-333/533 仅相对 Head40-733 改首层卷积核深度为 3/5。故完整体积与 Head40-733 的对比同时包含裁剪和浅层步幅调整，不能把差异全部归因于裁剪。 |
| ACB 卷积 | 以 Head40-733 为基础，仅把 Layer1 第一个残差块的第一个 3×3×3 卷积换成 3×3×3、1×3×3、3×1×3、3×3×1 四分支卷积，各分支经 BN 后相加。 |
| Layer2 保留深度 | 以 Head40-533 为基础，把 Layer2 首块的下采样步幅从 `(2,2,2)` 改为 `(1,2,2)`；深度 D 不在这一层减半，H/W 仍减半。 |
| 并行首层卷积 | 用 3×3×3 和 5×1×1 两条卷积分支替代 Head40-533 的单条 5×3×3 首层卷积；两个 64 通道输出经 BN 后相加，再激活。 |
| 横截面均值—深度最大池化 | 以 Head40-533 为基础，将 Layer4 的常规全局平均池化替换为：先对 H/W 求均值、保留 D，再沿 D 取最大值，得到 512 维分类向量。 |
| 全局平均/最大池化拼接 | Layer4 同时做全局平均池化 GAP 和全局最大池化 GMP，各得 512 维，拼成 1024 维向量后分类。 |
| 全局平均/轴向最大池化拼接 | Layer4 的 512 维 GAP 向量与“先 H/W 均值、再 D 最大值”的 512 维向量拼接，得到 1024 维后分类。 |
| Layer3 辅助分支 E1 | 保留原 Layer3→Layer4→GAP 主干；从 Layer3 另取 H/W 均值，保留 D=10，用一维卷积 `k=1` 将 256 通道投影为 128，再沿 D 取最大值；与主干 512 维向量拼成 640 维分类。 |
| Layer3 辅助分支 E2 | 在 E1 的 `k=1` 通道投影后，增加沿 D 方向的一维卷积 `k=3`，学习相邻深度位置关系；后续融合不变。 |
| Layer3 辅助分支 E3 | 把 E2 的单条 `k=3` 轴向卷积改成并行 `k=3`、`k=5`，各输出 64 通道，再拼成 128 通道；其余不变。 |
| Layer3 辅助分支 E4 | 在 E3 基础上，辅助分支同时提取 Layer3 的 H/W 均值和最大值并拼接，再做 `k=1` 投影与并行 `k=3/k=5` 轴向卷积；主干不变。 |
| 模糊样本固定权重 | 保持 Head40-533 模型和标签不变，仅把模糊样本的交叉熵权重设为 0.5 或 0.0，其他样本保持 1.0；模糊权重 1.0 即这组加权实验的 533 局部对照，并非整体基线。 |
| RACW 动态权重 | 保持 Head40-533 模型和标签不变；前 5 轮普通训练，之后由清晰样本建立两类特征中心，根据模糊样本对所属类中心的可靠度动态调整其损失权重，非模糊样本保持 1.0。 |

表中 `P/R/Sp` 分别为缺陷类 Precision、Recall、正常类 Specificity；`AUC/AP` 为 ROC-AUC、平均精确率。表格数值均为百分数，**只列五折均值**。

## 4. 结果分析

### 4.1 哪些改动确实有用

- **Head40 方案优于完整体积**：保持 7×3×3 首层卷积核，以完整体积原版对比 Head40-733，五折 F1 从 87.64% 到 88.86%（+1.22 个百分点），三板 F1 从 86.50% 到 88.58%（+2.08 个百分点）。但 Head40 同时调整了首层卷积与池化的深度步幅，因此这是整套 Head40 方案的收益，**不能仅归因于裁剪本身**。
- **533 与 733 是首层卷积核消融**：733 是保留原版 7×3×3 首层卷积的 Head40 主方法；533 将其改为 5×3×3，五折 F1 比 733 高 0.02 个百分点，但三板 F1 比 733 低 0.32 个百分点。两者接近，不能把微小差距解释为显著优势。
- **复杂结构没有稳定超越 Head40-733**：533 的 GAP+HWAvg-DMax 方案五折 F1 最高（89.27%），但三板只有 87.69%，低于 733 的 88.58%；E1～E4 三板 F1 为 87.71%～88.05%，也都低于 733。多数扩展实验应首先与各自的 533 局部对照比较，再与 733 这个 Head40 主方法比较；整体基线始终是原版完整体积模型。

### 4.2 模糊样本实验揭示的风险

以下是五折 OOF：训练池样本**每个只统计其所在折的验证预测一次**，不是训练集预测。表中只展示能归入清晰或模糊的样本，数值为“预测正确数/组内样本数”；清晰正常已合并上述补入的 87 个真实正常样本。其余 451 个未细分清晰/模糊的缺陷**仍参与训练、验证及总体指标**，只是没有放进这张分组表。

| 方案 | 清晰正常 | 模糊正常 | 清晰缺陷 | 模糊缺陷 |
|---|---:|---:|---:|---:|
| 模糊权重 1.0（533 局部对照） | 2223/2257 | 846/924 | 571/588 | **79/144** |
| 模糊权重 0.5 | 2221/2257 | 837/924 | 572/588 | 75/144 |
| 模糊权重 0.0 | 2234/2257 | 835/924 | 571/588 | **43/144** |
| RACW 动态加权 | 2230/2257 | 853/924 | 571/588 | **67/144** |

在 533 局部对照中，清晰缺陷检出 **97.11%**，模糊缺陷仅 **54.86%**，是当前最突出的错误集中点。把模糊样本权重降到 0 时，模糊缺陷检出从 79/144 降至 43/144，相比同结构 533 权重 1.0，五折 F1 降 **2.61** 个百分点，三板 F1 降 **3.64** 个百分点，故**不建议直接丢弃模糊样本监督**。权重 0.5 相比 533 局部对照，三板 Recall 从 90.45% 提至 92.07%，但 Precision 和 Specificity 下降，五折 F1 也略降，属于误报—漏报取舍，而非全面胜出。RACW 对模糊正常多判对 7 个、对模糊缺陷少检出 12 个，整体 F1 基本持平，未体现可靠增益。

注意：模糊缺陷检出率低**不等于**这些标签一定错误，也可能是缺陷本身较弱、裁剪定位或跨板分布造成。仅凭模型错误不能自动改标签。

### 4.3 板间差异不能被合并平均掩盖

Head40-733 主方法的三板 F1 分别为：0024 **84.02%**、0030 **77.60%**、0031 **91.92%**；对应缺陷 Recall 为 **77.30%**、**80.00%**、**95.39%**。0030 板的正常类 Specificity 仅 **89.64%**。因此要同时看每板漏检、误报和样本构成；只看 778 个样本的合并 F1，容易被较大的 0031 板掩盖。

## 5. 建议的下一步

1. **固定可复现参照**：以原版完整体积 3D ResNet18 为整体基线，以 Head40-733 为当前 Head40 主方法；在 E1～E4、池化、模糊权重和 RACW 等 533 派生实验内部，另以 Head40-533 普通交叉熵作为局部对照。均使用相同五折和 `best_loss` 口径。暂不继续扩大复杂结构搜索；模型选择首先依据五折，三板结果仅作已使用过的外部描述。
2. **先做困难样本核查**：汇总 OOF 中 144 个模糊缺陷的漏检清单，结合二维图、三维 Head40 裁剪位置、原始 RAW、不同折预测概率，由人工复核“真难例、标注争议、裁剪偏移、数据质量”四类原因；同时抽查 0030 板误报。复核记录与原标签分开保存，不直接让模型预测覆盖人工标签。
3. **执行已定的 IDO-GS 第一阶段**：按现有最终方案先跑普通 CE 的五折训练与逐轮错误轨迹，再运行 BMM 诊断。只有预设的结构门和模糊缺陷监督风险门都通过，才做第二阶段 IDO-GS 与同预算 CE 续训对照；若不通过，就停止动态降权路线。**目前结果目录没有这一方案的正式五折结果，本报告不把计划当成果。**
4. **补充真正面向新板的评估**：新增从未参与模型选择的板，尤其纳入经复核的模糊缺陷；预先固定模型与阈值，报告每板 Recall、Specificity、F1、误报/漏报数，并给出模糊缺陷检出率。若必须在当前三板上分析阈值，只能作为探索，不能再称其为盲测。

- 所有百分数是五折**算术均值**，小幅差异尚未经过配对不确定性分析，不能宣称统计显著。OOF 分组表与五折均值是**不同统计口径**，只用于定位错误，不直接拼表比较。
- 多次查看这三板结果会增加选择偏差；目前最可信的下一步不是再从三板分数中挑更复杂模型，而是核查困难标签，并建立新的前瞻性板级测试。

数据说明依据：[当前训练/验证数据集与独立测试集说明](当前训练验证数据集与独立测试集说明_20260806.md)。后续方案依据：[Head40 IDO-GS 最终实验方案](Head40_IDO_GS_最终实验方案.md)。指标核对自 `H:\3d钻孔缺陷分类实验结果_5折交叉验证_多板` 下的 `train_val`、`test` 汇总；分组数量核对自 `H:\多板数据集` 下训练池及三板测试的样本清单。
