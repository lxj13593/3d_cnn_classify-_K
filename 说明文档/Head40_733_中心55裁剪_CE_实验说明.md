# Head40-733：加载时中心55%裁剪实验

## 本次只改什么

从原始Head40加载体数据，在H、W方向按几何中心保留原尺寸的55%，D方向仍为40层。不新建数据集，不改RAW、不改标签、不重新划分五折，不加边缘Mask或去噪。

裁剪宽度为 `ceil(0.55 × 原宽)`，起点为 `floor((原宽 - 新宽) / 2)`。实际输入：

| 原始D×H×W | 裁剪后D×H×W | H/W切片区间（右端不包含） |
|---|---|---|
| 40×29×29 | 40×16×16 | [6, 22) |
| 40×37×37 | 40×21×21 | [8, 29) |
| 40×49×49 | 40×27×27 | [11, 38) |

29→16存在奇偶差，两侧去除6和7个体素，中心偏差0.5体素；与55%预览一致。框不会随亮区或标签移动。偏心或倾斜凸起仍可能碰框，55%并非自动确认的完整头部边界。

## 加载流程

原始Head40 RAW → 计算原始完整Head40的P1/P99 → 中心55% H/W裁剪 → 按原TOML信息统一D方向 → 仅训练集做原几何增强 → 使用原P1/P99归一化 → 仅训练集做原强度增强 → 模型。

裁剪和D轴翻转可交换顺序；验证、测试没有随机增强，输出与已确认的55%预览逐体素一致。不会用裁剪后区域重新计算P1/P99，也不会二次归一化、缩放或插值。训练的增强概率和±3体素平移范围保持原代码设置。

原始加载器不修改。`data_operate/head40_center_crop55.py`只做预处理适配，继承已有加载器的RAW读取、清单解析、方向统一、归一化和增强。按实际裁剪后尺寸组batch，不混合不同大小，不做padding拼批。

## 保持不变的设置

- 模型：原Head40-733 3D ResNet18；首层7×3×3，Dropout=0.5，GAP，二分类。模型本身不做裁剪，必须用本实验加载流程。
- 损失：训练、验证、测试均普通未加权CE；清晰/模糊、正常/缺陷都不额外加权，无Focal Loss。
- 清单：`datasets/resnet18_head40_toml_direction_unified_multiboard_5fold_clear_fuzzy_20260924`。沿用4364个训练/验证样本、22板、原五折成员；测试为锁定3板778个样本。
- 种子：42、123、2026、3407、777；50 epoch，batch size=4。
- AdamW，学习率1e-4，weight decay=1e-3；CosineAnnealingLR，eta_min=1e-7；CUDA时默认AMP。
- 阈值固定0.5；保存best_loss、best_f1、last，主比较用未加权验证CE最低的best_loss。
- 验证结果和外部测试结果分开；主比较只看best_loss各折独立指标的算术均值。测试默认完整保存best_f1、best_loss、last三个checkpoint的结果，同时保留原集成诊断文件，但汇报不展示集成指标。

## 文件与运行

新增文件按原目录放入同一项目：

1. `data_operate/head40_center_crop55.py`
2. `model/resnet18_3d_head40_stem733_crop55.py`
3. `train_val/main_resnet18_head40_stem733_crop55_ce_5fold.py`
4. `test/test_resnet18_head40_stem733_crop55_ce_3boards.py`

仍依赖项目中已有的 `data_operate/data_load_resnet18_head40_toml_direction_unified_multiboard.py`；不需要替换它。另一台电脑已有原数据和上述五折清单时，只拷贝这4个新增文件及本说明即可。数据应为未进行本次55%裁剪的原Head40，不要把预览NPZ当训练数据，也不要重复裁剪。

在项目根目录运行，或者在IDE中直接运行对应训练/测试文件：

```powershell
python train_val/main_resnet18_head40_stem733_crop55_ce_5fold.py
python test/test_resnet18_head40_stem733_crop55_ce_3boards.py
```

先完成五折训练，再运行测试；训练不自动调用外部测试。路径识别仍沿用原加载器。如果默认找不到数据，用实际路径显式指定，例如本机：

```powershell
python train_val/main_resnet18_head40_stem733_crop55_ce_5fold.py --dataset-root "H:\多板数据集\multiboard_head40_toml"
python test/test_resnet18_head40_stem733_crop55_ce_3boards.py --test-dataset-root "H:\多板数据集\test_3boards_head40_toml"
```

另一台电脑路径不同则改这两个参数，无需改脚本。若清单未在默认目录，用 `--split-root` 指向已有的同一套五折清单；不要重生成清单。
