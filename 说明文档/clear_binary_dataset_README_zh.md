# 明显二分类数据集说明

## 1. 数据集用途

本数据集用于钻孔三维体数据的正常/缺陷二分类，只收录当前已经筛选出的“明显正常”和“明显缺陷”样本，不包含尚未确定类别的模糊样本或困难样本。

- 数据板数量：15块（14块新增板和1块初始板）
- 明显正常样本：3262个
- 明显缺陷样本：1141个
- 样本总数：4403个
- 正常与缺陷数量比：2.86:1
- 每个样本均包含一份三维RAW和一张对应二维图

## 2. 数据来源与筛选规则

### 明显缺陷

明显缺陷来自人工复核后再次筛选出的清晰缺陷样本，按板保存在 `obvious_defects_by_board` 中，共1141个。

### 明显正常

正常候选从每块板的总体特征图中排除 `drill_ng` 对应孔后获得。抽样时再次按孔序号排除全部 `drill_ng` 和明显缺陷清单中的孔，只保留二维图与RAW均唯一对应的孔。

每块板的正常样本数量按下式确定：

```text
正常样本数 = max(100, 2 × 该板明显缺陷数)
```

抽样固定随机种子为 `20260731`。对于存在明显缺陷的板，正常样本的尺寸配额按照该板缺陷样本的尺寸比例分配，避免模型把尺寸当作类别线索；对于没有明显缺陷的板，因为不存在缺陷尺寸参照，正常样本继续按照候选池的尺寸比例分层。每种尺寸内部再划分5个灰度区间进行抽样，以减少灰度分布抽偏。抽样结果按板保存在 `normal_samples_by_board` 中。

## 6. 完整性检查

- 正常RAW：3262份；正常二维图：3262张
- 缺陷RAW：1141份；缺陷二维图：1141张
- RAW与二维图按“板号 + 孔序号”一一对应
- 正常样本与 `drill_ng` 的孔序号交集为0
- 正常样本与明显缺陷清单的孔序号交集为0
- 正常样本无重复“板号 + 孔序号”
- 所有复制文件均已进行SHA-256一致性校验
- 原始数据目录未修改

## 7. 使用说明

训练、验证和测试划分时，三维RAW与对应二维图必须始终作为同一个样本处理。若后续加入模糊样本，应另建“困难正常”和“困难缺陷”目录并保留独立清单，不要直接混入本明显数据集后再进行随机划分。
