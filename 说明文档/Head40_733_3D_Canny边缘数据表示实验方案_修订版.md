# Head40-733 3D Canny 边缘数据表示实验方案（修订版）

日期：2026-10-05

## 1. 这轮实验主要做什么

当前任务仍然是钻孔正常／缺陷二分类。这轮不继续修改模糊样本权重，也不修改网络结构和损失函数，只验证：

> 在现有 Head40 中保留边缘附近的原始灰度，屏蔽非边缘区域，是否比直接输入 Head40 更容易识别头部微小凸起和不规则形态？

这里的“边缘表示”不是把缺陷变清晰，也不是增加新的观测信息，而是从原始体数据中筛选信息。它可能减少金属内部区域的干扰，也可能误删弱凸起，因此必须先检查表示是否保留了可见的缺陷。

参考肺结节论文的“边缘 Mask → 膨胀 → 与原图相乘”思路，但不照搬肺分割、HU 阈值、GLCM、病理特征标注或额外注意力模块。

本文件是实验方案，尚不代表代码已经实现或实验已经运行。

## 5. 固定的三维 Canny-style 实现

本轮采用明确包含三维非极大值抑制和三维连通跟踪的 **3D Canny-style** 算法。不同库的 Canny 实现未必逐体素等价，整轮实验固定同一实现和版本，不临时替换。

不能用逐切片的二维 Canny 代替本实验；也不能省略非极大值抑制后仍称“等价 Canny”。Gaussian、非极大值抑制、滞后阈值处理是 Canny 的关键步骤。[ITK 官方说明](https://docs.itk.org/projects/doxygen/en/stable/classitk_1_1CannyEdgeDetectionImageFilter.html)

### 5.1 Gaussian 与梯度

固定：

```text
S = Gaussian(I)
sigma = (1.0, 1.0, 1.0) voxel，顺序 D/H/W
mode = reflect
truncate = 4.0

Gd, Gh, Gw = numpy.gradient(S, edge_order=1)
梯度间距 = (1,1,1) voxel
G = sqrt(Gd² + Gh² + Gw²)
```

梯度采用内部中心差分、边界一阶单边差分，固定使用同一规则。[NumPy gradient 说明](https://numpy.org/doc/stable/reference/generated/numpy.gradient.html)

Gaussian 只服务于 Mask 生成；最终强度仍来自未平滑的 I。sigma 用体素单位，不把这个设置解释成已经按真实毫米尺度统一，也不在本轮额外插值重采样。

**注意：只平滑 Mask 分支，不保证小凸起不会丢失。若小凸起没有被 Mask 覆盖，最终乘原图也无法恢复。** sigma=1 是本轮预设起点，不是已经证明最优的参数。

### 5.2 三维非极大值抑制（NMS）

对梯度非零的体素位置 r，计算单位梯度方向：

```text
n = (Gd, Gh, Gw) / G
```

沿真正的三维方向，在 `r+n` 与 `r-n` 两处对 G 做三线性插值比较：

```text
当前 G 不小于两侧插值值 → 保留
否则 → 置 0
```

得到 `G_nms`。插值固定为 `order=1`；无有效梯度的体素置零；任一比较点落到 ROI 外时，该体素不作为 NMS 候选。不能用六邻域最大值或任意局部最大值替代沿梯度方向的比较。

### 5.3 双阈值与三维连通跟踪

用本折训练集确定的统一 high／low：

```text
strong = G_nms >= high
candidate = G_nms >= low
```

在 candidate 中按 **26 邻接**计算三维连通分量，只保留含至少一个 strong 体素的分量，得到二值 EdgeMask。没有 strong 时，Mask 为全零，并记录该样本，不能偷偷降低阈值补救。

### 5.4 一次轻度膨胀

```text
DilatedMask = binary_dilation(EdgeMask)
structure = 全 1 的 3×3×3 立方体
iterations = 1
border_value = 0
```

明确使用全 1 结构元素，不能依赖库默认结构元素，因为默认连通结构未必是完整的 3×3×3 立方体。[SciPy 膨胀说明](https://docs.scipy.org/doc/scipy/reference/generated/scipy.ndimage.binary_dilation.html)

这一步不填充整个金属内部，不进行额外闭运算、孔洞填充或凸包处理。

## 6. 每折训练阈值怎么确定

每折仅使用该折训练清单，且仅使用无增强的原图 I，按第 5.1 节计算 S 与 G。

**P90 统计明确发生在 Gaussian 后、NMS 前的梯度幅值 G 上。** 实际边缘检测使用同一 Gaussian、同一梯度算法生成 G_nms，不混用未平滑梯度、Sobel 梯度或其他单位。

第一轮沿用原方案的“全部有效非零梯度汇总”规则：

```text
V = 当前训练折所有样本 G 中有限且 > 0 的值
high = P90(V)，百分位插值方法固定为 linear
low = 0.5 × high
```

此规则是体素汇总，不是每个样本等权；较大横截面可能贡献更多梯度值。第一轮固定并记录这个定义，不在训练中切换到按样本抽样或按类别平衡统计。

可以分块读取／用临时存储降低内存峰值，但不能无记录地用少量抽样近似替换上述阈值定义。过滤 NaN／Inf／零值不等于可以忽略异常输入；若归一化原图本身存在非有限值，应报错排查。

不使用验证集、外部三板、正常／缺陷标签或清晰／模糊标签决定阈值。不按单个样本重新估计阈值，不随 epoch、验证指标或当前预测调整阈值。

如果有效梯度集合为空，或者 high 非有限／不大于零，停止该折并说明原因，不能使用任意默认值继续训练。

每折阈值只计算一次。对应的训练、验证和外测全部使用同一组值；外测不同折使用各自训练折的参数，不能五折共用 fold 0 的参数。

## 7. 正确的数据增强顺序

训练时固定以下流程：

```text
无增强归一化原图 I
        │
        └→ Gaussian → 三维梯度 → NMS → 双阈值连通跟踪
                                            → 膨胀 → M

(I, M) 同步执行相同的 H/W 几何增强
        │
        ├→ I_geo → 现有强度增强 → I_aug
        └→ M_geo

D0 输入：I_aug
D1 输入：I_aug × M_geo
```

保留现有增强参数：

| 增强 | 设置 |
|---|---|
| H/W 翻转 | 概率 0.5 |
| H/W 90°倍数旋转 | 概率 0.5 |
| H/W 平移 | 概率 0.5，范围 [-3,3] 体素 |
| 随机加噪 | 概率 0.5，标准差范围 [0.01,0.03] |
| 亮度变化 | 概率 0.5，系数范围 [0.9,1.1] |
| 对比度变化 | 概率 0.5，系数范围 [0.9,1.1] |

原图与 Mask 共享同一次几何变换参数，平移采用原来的零填充，不环绕。Mask 保持二值，不加噪声，不做亮度或对比度增强。强度增强顺序仍为加噪、亮度、对比度。

**最后再乘 Mask。** 不能生成 EdgeHead40 后直接执行全部强度增强而不重新遮罩：噪声会填入非边缘区域，对比度变化也可能把 0 背景变成正值。

增强不能改变 D 方向。阈值统计、缓存和可视化使用独立流程，不消耗正式训练的采样／增强随机数状态。

验证与测试无随机增强：

```text
D0：I
D1：I × M
```

不要对生成后的 EdgeHead40 再做一次 P1/P99 归一化，否则会额外改变保留区域的强度。

## 8. 正式训练前的必要检查

先使用 fold 0 的训练阈值，从 fold 0 训练集选 20 个样本：正常 10、缺陷 10，尽量覆盖不同训练板、横截面以及清晰／模糊分组。选样仅用于检查，不参与阈值的标签加权。

每个样本保存相同位置的：

```text
归一化原图 I
EdgeMask
DilatedMask
I × DilatedMask
```

同时记录样本 ID、板号、类别、difficulty、Mask 体素占比。至少查看能显示头部形态的 D-H／D-W 视图及相关横截面，不能只看一个无缺陷经过的切片。

只检查这些必要事项：

1. 原图、Mask、边缘表示尺寸和方向是否一致。
2. 肉眼可见且能定位的小凸起，是否仍落在 Mask 保留区域。
3. 是否存在大量内部噪声边缘、裁剪边界伪边缘或明显断裂。
4. 是否频繁出现全零／几乎全满 Mask，并解释原因。
5. 训练增强后，非边缘区域是否确实仍为零。

对难以确定的模糊样本，不通过这次可视化改类别标签。检查使用训练样本，不查看外测样本来改参数。

如果实现正确但可见小凸起被系统性删除，先停止当前配置，不直接跑五折。任何 sigma／阈值／膨胀修改都应在正式训练前另记版本，不能一边看验证结果一边改变同一实验的表示。

## 9. 五折训练与结果判断

必要检查通过后，训练 D1 五折。主结果始终是各折 `best_loss` 对应的指标。

验证集与外部测试集分开比较，不混成一张总表。五折结果采用指标的算术均值，不把 OOF 指标或五折概率集成指标冒充五折均值。

统一保留：Loss、Accuracy、Precision、Recall、F1、Specificity、AUC、AP，以及 TP／TN／FP／FN。清晰／模糊分组仍按现有方式保存，模型输出仍是两类。

验证比较重点：

- F1 是否提高，以及这种方向是否出现在大部分折，而非仅靠一折拉高均值。
- 召回率提高时，精确率是否明显下降，避免再次只换取更多误报。
- AUC／AP 是否与阈值下的指标一致，是否存在只改善单个指标的情况。

汇报只展示五折均值；逐折结果保留，用于必要时核查。很小的均值变化只能说有初步信号，不能仅凭一次五折就宣称统计显著或稳定泛化提升。

D1 若 F1 下降、召回也没有改善，停止这一个“纯边缘硬掩膜＋固定参数”的配置，不大规模搜索参数。若有正向信号，则固定全部设置，运行对应的外部三板评估。

**D1 不好，不等于全部边缘表示都无效。** 本轮同时改变了“突出边缘”和“删除非边缘信息”；负结果不能直接否定保留原图的辅助边缘方案。

## 13. 执行顺序
